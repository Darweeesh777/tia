# روفا × توتا — آخر مهمة قبل الميري

موقع ثابت مستقل، بالعربية ومناسب للموبايل. افتح `index.html` مباشرة أو شغّل:

```powershell
python -m http.server 5173 --bind 127.0.0.1 --directory C:\Gindi-website\tota-mission
```

ثم افتح http://127.0.0.1:5173 . للنشر ارفع محتويات هذا المجلد لأي استضافة مواقع ثابتة.

## الصور
ضع صور روفا داخل `assets` وأضفها بالترتيب في `photos.js`. كل محاولة رفض تعرض الصورة التالية مع تعليقها. حتى إضافة الصور يظهر الإفيه وحده بدون صور مكسورة أو صور أشخاص بديلة.

## السلوك
- ست شاشات، الدعوة تظهر في الرابعة. فتح الموقع من جديد يبدأ بالغموض.
- زر الرفض يهرب داخل مساحة مستقلة بالماوس واللمس، ولا يغطي زر الموافقة.
- اختيار الجمعة 30 أكتوبر 2026 أو السبت 31 أكتوبر 2026. لا وقت محدد والمكان سري.
- رابط واتساب يفتح رسالة باليوم المختار إلى 201557071568؛ لا يرسل تلقائيًا.
- لا جمع بيانات أو تتبع أو تسجيل موافقات على خادم.
- الخطوط من Google Fonts مع خطوط بديلة عند انقطاع الإنترنت.

## الإضافات التفاعلية
- البصمة تفاعل للضغط المطول ثانيتين (ماوس/لمس أو Enter/Space)، وليست جمع بيانات بيومترية. رفع الضغط مبكرًا يلغي المحاولة.
- لجنة الاعتذارات تعرض دراسة قصيرة وقرارًا مع كل محاولة رفض.
- زر الشكاوى يفتح حوارًا بإفيهات متغيرة، ويمكن إغلاقه بزر الإغلاق أو Escape.
- التذكرة تُولد محليًا كصورة PNG حسب اليوم المختار.
- لتفعيل الرسالة الصوتية ضع التسجيل داخل assets ثم اضبط window.rofaVoiceSrc في extras.js. الزر مخفي حتى إضافة التسجيل الحقيقي، ولا يوجد تشغيل تلقائي.
